# AksesBogor Web

Aplikasi web AksesBogor: informasi aksesibilitas fasilitas publik di Kota Bogor, dibuat mobile-first dan bisa dipasang sebagai PWA ([ADR-0012](https://github.com/al-dioooo/akses-bogor-docs/blob/main/decisions/0012-web-mobile-first-pwa.md)). Dibangun dengan Next.js dan di-deploy ke Vercel ([ADR-0013](https://github.com/al-dioooo/akses-bogor-docs/blob/main/decisions/0013-tech-stack-nextjs-fastify.md)).

Repo ini sedang disiapkan. Petunjuk menjalankan, environment variables, dan deployment ditambahkan bersama kerangka proyek.

Keputusan produk dan teknis ada di [akses-bogor-docs](https://github.com/al-dioooo/akses-bogor-docs). Aturan kontribusi ada di [AGENTS.md](AGENTS.md).
